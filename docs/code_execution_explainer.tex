\section{The two simulation loops}

The Streamlit entry point is \file{app.py}.  A hidden initialization loop first
constructs inherited economic history under an automated central-bank persona.
The visible loop then advances one quarter whenever the player submits an
interest rate.  Streamlit retains the \code{Economy} instance in session state
between reruns.

On a visible turn the player sees information through $t-1$, submits $i_t$, and
calls \code{Economy.simulate\_quarter()}.  The outcomes dated $t$ become visible
on the next turn.  The compact execution path is
\[
 \boxed{i_t\text{ chosen}}
 \longrightarrow\boxed{\text{events and shocks}}
 \longrightarrow\boxed{\text{model equations}}
 \longrightarrow\boxed{\pi_t,u_t,\text{history}}.
\]
The current rate is stored at the end of the calculation and first affects the
output gap in $t+1$.

\section{One call to \code{simulate\_quarter}}

\begin{enumerate}
  \item \code{event\_snapshot} gives the event engine information through the
  start of the quarter.  At most one eligible new event is selected, and the
  effects due from all active schedules are consumed.
  \item \code{generate\_shocks} draws innovations for inflation, demand,
  natural unemployment, and the natural real rate.  Difficulty scales their
  standard deviations.
  \item Natural unemployment and the natural real rate mean-revert toward
  their configured anchors before the current model outcome is calculated.
  \item \code{calculate\_interest\_rate\_pressure} reads the final stored real
  rate and natural rate---the observations from $t-1$---and updates $R_t$.
  \item \code{calculate\_quarter\_outcome} evaluates the economic equations in
  the same order as \code{docs/economic\_model.tex}.
  \item The coordinator commits inflation, the output gap, and unemployment;
  updates reputation; records the current ex-ante real rate; and appends one
  history row.
\end{enumerate}

\section{The equation functions in execution order}

\subsection*{1. Inflation expectations}
\code{calculate\_expected\_inflation} evaluates
\[
 E_t\pi_{t+1}=A_tk_a\pi_t^*+(1-A_tk_a)\pi_{t-1}.
\]
Reputation $A_t$ and its coefficient $k_a$ are both calibrated in $[0,1]$.

\subsection*{2. Output-gap expectations}
\code{calculate\_expected\_output\_gap} evaluates
\[
 E_t\gap_{t+1}=\phi\gap_{t-1}.
\]
The function validates that $\phi$ lies between zero and one.

\subsection*{3. The real rate and lagged rate stock}
When a quarter is recorded, \code{calculate\_real\_interest\_rate} calculates
\[
 r_t=i_t-E_t\pi_{t+1}.
\]
At the beginning of the next model calculation,
\code{calculate\_interest\_rate\_pressure} uses that stored observation:
\[
 R_t=\rho R_{t-1}+(1-\rho)(r_{t-1}-r^n_{t-1}).
\]
This indexing is what prevents the newly submitted $i_t$ from changing current
output.

\subsection*{4. Modified dynamic IS equation}
\code{dynamic\_is\_equation} computes the unconstrained output gap:
\[
 \gap_t^{\mathrm{IS}}
 =\phi\gap_{t-1}-\frac{R_t}{\widetilde\sigma}+\varepsilon_{d,t}.
\]
The code keeps the expectation calculation separate, so the IS function
receives $E_t\gap_{t+1}$ as an explicit argument.

\subsection*{5. Capacity guardrail}
\code{calculate\_maximum\_output\_gap} combines Okun's law with minimum
unemployment:
\[
 \gap_t^{\max}=\frac{u_t^n-u^{\min}}{\lambda_u}.
\]
\code{apply\_output\_capacity} then evaluates
$\gap_t=\min\{\gap_t^{\mathrm{IS}},\gap_t^{\max}\}$.

\subsection*{6. Phillips curve and deflation guardrail}
\code{phillips\_curve\_gap\_effect} applies the same slope $\kappa$ to positive
and negative output gaps. Then
\code{new\_keynesian\_phillips\_curve} computes
\[
 \pi_t^{\mathrm{raw}}
 =\beta E_t\pi_{t+1}+\kappa\gap_t+\varepsilon_{\pi,t}.
\]
If raw inflation is negative, \code{calculate\_quarter\_outcome} multiplies it
directly by the configured slowdown ratio $d$, then imposes the $-99$ percent
floor.

\subsection*{7. Okun's law}
Finally, \code{okuns\_law} translates the hidden output gap into the labor-market
outcome shown to the player:
\[
 u_t-u_t^n=-\lambda_u\gap_t.
\]
The output gap remains in state and history because it is needed by next
quarter's expectation, capacity, and inflation calculations.

\section{Settings and compatibility}

The settings screen is grouped by the new model's concepts: output-gap and
monetary transmission, inflation and unemployment, expectations and targets,
events, and background processes.  It no longer displays aggregate-demand,
aggregate-supply, or numerical-solver controls because the model is evaluated
sequentially and has no numerical curve-intersection solver.

\file{settings\_code.py} serializes only active parameters.  Its decoder also
recognizes the two older PIRS2 schemas, removes obsolete fields, and supplies
defaults for new coefficients.  Thus an old
shared settings string can still start the revised model without keeping dead
controls in the interface or the parameter object.

\section{State after a quarter}

\code{ModelResult} contains only the current inflation rate, unemployment rate,
output gap, and expected inflation.  \code{Economy.\_commit\_motion} transfers
those values to \code{EconomicIndicators}.  \code{EconomicHistory.append}
then stores them together with the nominal rate, ex-ante real rate, natural real
rate, effective rate stock, reputation, shocks, and event names.  The result
object is temporary; the indicator and history objects are the durable state
used on the next turn.
